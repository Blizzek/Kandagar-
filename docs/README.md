# Кандагар - Система управления БПЛА

Веб-приложение на русском языке с авторизацией, управлением пользователями, интерактивной картой и системой координат СК-42 для управления объектами БПЛА.

## Возможности

- ✅ Трехуровневая система ролей (Creator, Admin, Operator)
- ✅ Интерактивная карта с объектами (OpenStreetMap)
- ✅ Версионирование объектов с историей перемещений
- ✅ Система координат СК-42 (зона 37, Гаусс-Крюгер)
- ✅ Автоматическая конвертация СК-42 ↔ WGS-84
- ✅ Управление пользователями (для Creator)
- ✅ Блокировка по IP после неудачных попыток входа (3 попытки / 5 минут)
- ✅ Журналирование входов
- ✅ Экспорт данных в Word (.docx)
- ✅ Маршруты БПЛА (все версии объекта)
- ✅ Хранение данных в SQLite
- ✅ Портативная версия с Node.js

## Технологии

- **Backend**: Node.js + Express
- **База данных**: SQLite
- **Карты**: Leaflet + OpenStreetMap
- **Координаты**: proj4 (СК-42 ↔ WGS-84)
- **Экспорт**: docx (генерация Word документов)
- **Frontend**: HTML, CSS, JavaScript
- **Безопасность**: bcryptjs, express-session

## Система координат

Проект использует **СК-42 (зона 37)** - российскую военную систему координат Гаусса-Крюгера:
- **Эллипсоид**: Красовского
- **Проекция**: Поперечная Меркатора
- **Центральный меридиан**: 39°
- **Смещение**: X₀ = 37 500 000 м
- **Параметры трансформации**: +towgs84=24,-123,-94,0,0,0,0

Координаты:
- **Хранение**: в СК-42 (метры)
- **Отображение**: автоматическая конвертация в WGS-84 для карты
- **Ввод**: через карту (WGS-84) с автоконвертацией в СК-42

## Роли пользователей

### Creator (Создатель)
- Полный доступ ко всем функциям
- Управление администраторами и операторами
- Создание/удаление пользователей
- Полный доступ к объектам на карте
- Экспорт данных в Word

### Admin (Администратор)
- Управление операторами
- Создание/удаление операторов
- Полный доступ к объектам на карте
- Просмотр и редактирование объектов
- Экспорт данных в Word

### Operator (Оператор)
- Просмотр объектов на карте
- Добавление новых объектов
- Просмотр маршрутов БПЛА
- Экспорт данных в Word
- Ограниченный доступ (без удаления)

## Установка

### Вариант 1: Стандартная установка

1. Установите Node.js с https://nodejs.org/

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер:
```bash
npm start
```

4. Откройте браузер: http://localhost:3000

### Вариант 2: Портативная версия (полностью автономная)

1. Запустите `start-portable.bat`
   - Автоматически использует портативный Node.js из папки `node-portable`
   - Не требует установки Node.js в системе
   - Работает полностью офлайн

## Работа с объектами

### Создание объекта
1. Нажмите "Добавить объект"
2. Укажите название, частоту
3. Кликните на карту или введите координаты (WGS-84)
4. Система автоматически конвертирует в СК-42

### Версионирование (маршрут БПЛА)
- При редактировании объекта создается новая версия
- Старые версии сохраняются
- Все версии доступны через `GET /api/object-route/:original_id`
- История перемещений отображается на карте

### Экспорт в Word
1. Нажмите "Экспорт в Word"
2. Скачается .docx файл со всеми объектами
3. Данные группируются по объектам с историей версий
4. Включает СК-42 координаты, даты, частоты

## API Endpoints

### Авторизация
- `POST /api/creator-login` - вход создателя
- `POST /api/user-login` - вход админа/оператора
- `POST /api/logout` - выход
- `GET /api/check-auth` - проверка авторизации

### Управление пользователями (Creator)
- `POST /api/users/create` - создание пользователя
- `POST /api/users/delete` - удаление пользователя
- `GET /api/users` - список пользователей

### Объекты (Admin/Operator)
- `GET /api/objects` - последние версии объектов (СК-42 → WGS-84)
- `POST /api/objects/create` - создание/редактирование (WGS-84 → СК-42)
- `POST /api/objects/delete` - удаление версии
- `GET /api/object-route/:original_id` - маршрут (все версии)
- `GET /api/objects/next-number` - следующий номер

### Экспорт
- `GET /api/export/word` - выгрузка в Word (.docx)

## Структура БД

### Таблицы пользователей
- `creators` - создатели системы
- `admins` - администраторы
- `operators` - операторы

### Таблица объектов
```sql
objects (
  id INTEGER PRIMARY KEY,
  original_id INTEGER,  -- для версионирования
  object_number TEXT,
  datetime DATETIME,
  name TEXT,
  frequency TEXT,
  x REAL,              -- СК-42 X (восток, метры)
  y REAL,              -- СК-42 Y (север, метры)
  by_snail TEXT,
  created_at DATETIME
)
```

### Безопасность
- `login_attempts` - попытки входа и блокировки
- `login_logs` - журнал всех входов

## Безопасность

- Пароли хешируются через bcryptjs
- Сессии с httpOnly и sameSite cookies
- Блокировка IP после 3 неудачных попыток на 5 минут
- Логирование всех попыток входа с IP и ролью
- Разделение прав доступа по ролям
