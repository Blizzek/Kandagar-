**I. Приложение оператора (администратора):**

При установке, посту присваивается порядковый номер, идентифицирующий его обнаружения в базе данных.

При запуске приложения, предлагается ввести номер поста и пароль для идентификации оператора.

![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image002.png)

  

После осуществления входа, появляется окно с одной кнопкой ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image004.jpg), служащей для добавления окна БпЛА, при этом номер поста отображается в левом верхнем углу окна. Кнопку можно нажимать неоднократно, при наличии активных окон «Информация о БпЛА».

![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image006.png)

При нажатии кнопки добавления БпЛА, появляется окно ввода, где № БпЛА присваивается согласно порядкового номера из базы данных. То есть, если в базе данных имеется информация о 45 БпЛА, то после нажатия на кнопку добавления БпЛА новому БпЛА присвоится номер 46. Время и дата берутся автоматически из системного времени операционной системы. Телеметрия, квадрат (Х и Y) вводятся в ручную. «Улитка» также вводится вручную, если оператор не вводит «улитку», то по умолчанию переменной присваивается значение 9.

После ввода информации о БпЛА нажимается кнопку ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image008.jpg) «Подтвердить информацию о БпЛА». После нажатия данной кнопки, на карте клиента отображается значок БпЛА в указанном квадрате.

При нажатии кнопки ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image010.jpg) «Завершить информирование о БпЛА», вся информация из окна БпЛА сохраняется в базе данных. При этом окно БпЛА пропадает из главного меню.

![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image012.png)

Кнопка ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image014.jpg) дополнения информации о БпЛА. После ее нажатия, появляется дополнительное окно, где номер, дата, время и название БпЛА переносятся автоматически. Частота, квадрат (Х, Y) и «улитка» вводятся оператором вручную. После ввода информации, для ее отображения на карте вновь нажимается кнопка «Подтвердить информацию о БпЛА» ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image016.jpg). После нажатия данной кнопки, на карте клиента отображается значок БпЛА в измененном квадрате.

Бывают случаи, когда необходимо создать для одного БпЛА более 20 окон информирования о БпЛА. Такое количество окон будет мешать оператору в процессе работы, поэтому необходима возможность сворачивания этих окон специальной кнопкой ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image018.png).

Значение остальных кнопок остается прежним. Добавление новых окон при изменении квадрата полета БпЛА и кнопка завершения (при падении БпЛА).

![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image020.png)

          Взаимодействие с сервером в данном приложении осуществляется только при нажатии кнопки «Завершить информирование о БпЛА» ![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image022.jpg). Тогда вся собранная информация из окон информации о БпЛА сохраняются в строке таблицы базы данных.

**Проблемные вопросы:**

Бывают случаи, когда один Пост видеоперехвата теряет картинку, но второй пост видит изображение. Если блок создал Пост № 1, но потерял картинку, как продолжить его маршрут Посту № 2.

**II. Приложение клиента**

Для конечного пользователя («Клиента») информация должна доводиться максимально просто и без возможности что-то редактировать. Необходимо рассмотреть возможность установки приложения только доверенным лицам, для этого стоит рассмотреть возможность формирования уникального ключа для каждого установленного приложения Администратором сервера.

Карта в приложении клиента масштабируется. На карте отображается местоположение БпЛА на местности. Дополнительно в приложении клиента отображается краткая информация о летящем БпЛА (телеметрия, квадрат, частота).

![](file:///C:/Users/9AF8~1/AppData/Local/Temp/msohtmlclip1/01/clip_image024.png)

**III. Сервер (база данных)**

Сервер хранит информацию в базе данных о всех БпЛА, отправленных операторами. Выгрузку с сервера операторы не имеют права делать. Это возможность есть только у администратора Сервера.

Клиент запрашивает каждые 40 секунд данные с Сервера для отображения актуальной информации на карте.

База данных представляет собой таблицу со следующими данными:

|   |   |   |   |   |   |

При этом сортировка возможна по любому наименованию столбца, но за определенный период. Фильтрация для отображения части информации возможна по названию, частоте, дате и времени с указанием периода, квадрату, № поста.
