# Кандагар - Система управления БПЛА

Веб-приложение на русском языке с авторизацией и интерактивной картой для управления метками.

## Возможности

- ✅ Авторизация пользователей
- ✅ Интерактивная карта с метками
- ✅ Хранение меток в базе данных
- ✅ Добавление и удаление меток
- ✅ Русскоязычный интерфейс

## Технологии

- **Backend**: Node.js + Express
- **База данных**: SQLite (better-sqlite3)
- **Карты**: Leaflet + OpenStreetMap
- **Frontend**: HTML, CSS, JavaScript

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер: http://localhost:3000

## Использование

### Авторизация
- Логин: `admin`
- Пароль: `admin`

### Работа с картой
1. После входа откроется интерактивная карта
2. Нажмите кнопку "Добавить метку" для создания новой метки
3. Укажите координаты (можно кликнуть по карте)
4. В списке слева отображаются все метки
5. Клик по метке в списке центрирует карту на ней
6. Для удаления метки нажмите кнопку "Удалить"

## API

### Авторизация
- `POST /api/login` - Вход
- `POST /api/logout` - Выход
- `GET /api/check-auth` - Проверка авторизации

### Метки
- `GET /api/markers` - Получить все метки
- `POST /api/markers` - Добавить метку
- `DELETE /api/markers/:id` - Удалить метку
