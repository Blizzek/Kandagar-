# Changelog - Обновление системы Кандагар

## Версия 2.0 - Интеграция функций из BPLA

### Основные изменения

#### 1. Система координат СК-42
- ✅ Добавлена поддержка российской военной системы координат СК-42 (зона 37)
- ✅ Автоматическая конвертация между СК-42 и WGS-84
- ✅ Хранение в БД в СК-42 (метры), отображение на карте в WGS-84
- ✅ Модуль `coordinate-converter.js` для конвертации

**Параметры СК-42:**
- Эллипсоид Красовского
- Проекция Гаусса-Крюгера
- Центральный меридиан: 39°
- Смещение: X₀ = 37 500 000 м
- Трансформация: +towgs84=24,-123,-94,0,0,0,0

#### 2. Версионирование объектов
- ✅ При редактировании создается новая версия (старая сохраняется)
- ✅ Поле `original_id` для связи версий
- ✅ Endpoint `/api/object-route/:original_id` для получения маршрута БПЛА

#### 3. Экспорт данных в Word
- ✅ Endpoint `/api/export/word` для выгрузки всех объектов
- ✅ Генерация .docx с таблицами объектов
- ✅ Группировка по `original_id` с историей версий
- ✅ Кнопка экспорта в интерфейсе

#### 4. Расширенная структура объектов
Поля объекта БПЛА:
- `object_number` - номер объекта
- `datetime` - дата и время
- `name` - название
- `frequency` - частота (МГц)
- `x, y` - координаты СК-42 (метры)
- `by_snail` - "по улитке" (метод обнаружения)
- `original_id` - ID оригинала для версий

#### 5. API Changes

**Обновленные endpoints:**
- `GET /api/objects` - теперь возвращает `lon/lat` (WGS-84) + `x/y` (СК-42)
- `POST /api/objects/create` - принимает `lon/lat`, конвертирует в СК-42
- `GET /api/object-route/:original_id` - новый endpoint для маршрутов

**Новые endpoints:**
- `GET /api/export/word` - экспорт в Word (.docx)

### Миграция данных

Старая структура:
```javascript
{
  latitude: 55.7558,
  longitude: 37.6173
}
```

Новая структура:
```javascript
{
  x: 37500000,           // СК-42 X (метры)
  y: 6200000,            // СК-42 Y (метры)
  lon: 37.6173,          // WGS-84 (для карты)
  lat: 55.7558           // WGS-84 (для карты)
}
```

### Frontend Changes

1. **Обновлены поля ввода:**
   - Было: X (координата), Y (координата)
   - Стало: Широта (Latitude), Долгота (Longitude)

2. **Добавлена кнопка экспорта:**
   - "📄 Экспорт в Word"

3. **Обновлены popup'ы маркеров:**
   - Показывают СК-42 и WGS-84 координаты

### Что НЕ было перенесено

❌ Офлайн-карты (tiles из .mbtiles)
❌ Автоматическая выгрузка каждые 5 минут (APScheduler)
❌ Изменение порта (остается 3000)

### Breaking Changes

⚠️ **API несовместимость:**
- `POST /api/objects/create` теперь требует `lon/lat` вместо `x/y`
- `GET /api/objects` возвращает дополнительные поля `lon/lat`

⚠️ **База данных:**
- Требуется пересоздание БД (координаты теперь в СК-42)
