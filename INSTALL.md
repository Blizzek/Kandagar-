# Инструкция по установке и запуску Kandagar

## Вариант 1: Стандартная установка (требует интернет)

### Первоначальная настройка:
1. Установите Node.js с https://nodejs.org/ (если не установлен)
2. Запустите `setup.bat` - установит все зависимости
3. Запустите `start.bat` - запустит сервер

### Запуск сервера:
- Просто запустите `start.bat`
- Откройте браузер: http://localhost:3000

---

## Вариант 2: Полностью офлайн (портативная версия)

### Подготовка портативной версии:

1. **На компьютере с интернетом:**
   ```bash
   npm install
   ```

2. **Скопируйте весь проект** включая папку `node_modules`

3. **Скачайте портативный Node.js:**
   - Перейдите на https://nodejs.org/
   - Скачайте Windows Binary (.zip)
   - Распакуйте в папку `node-portable` внутри проекта

4. **Структура портативной версии:**
   ```
   Kandagar-/
   ├── node-portable/      # Портативный Node.js
   ├── node_modules/       # Установленные зависимости
   ├── public/
   ├── server.js
   ├── package.json
   ├── start-portable.bat  # Запуск без системного Node.js
   └── setup.bat
   ```

5. **Используйте `start-portable.bat`** для запуска

Теперь проект можно перенести на любой компьютер без интернета и Node.js!

---

## Решение проблем

### Node.js не найден
- Установите Node.js или используйте портативную версию

### Ошибки при установке зависимостей
- Проверьте подключение к интернету
- Запустите PowerShell/CMD от администратора
- Очистите кэш: `npm cache clean --force`

### Порт 3000 занят
- Измените порт в `server.js` (строка 8)
- Или остановите процесс на порту 3000
